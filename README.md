# TeamUp
A simple way for college students to discover, join, and participate in campus intramural and club sports.

## Project Description/Motivation
TeamUp is a student-focused app designed to simplify the process of discovering and joining on-campus intramural and club sports. The app provides a user-friendly platform where students can explore available sports, find teams, view schedules, and complete registration.

TeamUp was created in response to the current challenges students face when trying to navigate the current campus registration system. Complicated, cluttered interfaces and unintuitive sign up processes can discourage students from participating in on-campus sports. By prioritizing simplicity, accessibility, and easy navigation, TeamUp's goal is to remove these barriers and encourage higher student involvement in campus sports.

## Target Users

TeamUp is designed for college students who want to stay active, meet new people through club sports, and become more involved on campus. Whether students are trying to join a competitive club sport or participate in a light-hearted intramural league, TeamUp provides a simple way to find and join their desired club.

## Features

- Club Discovery

  Browse available campus sports club and learn about membership

- Intramural and Club Sports

  Explore sports, clubs, divisions, registration details, and teams

- Search

  Search for specific clubs and intramural leagues

- Gender filters

  Join clubs based on divisions (men, womens, open)

- Registration Waiver

  Review and accept a liability waiver before submitting a join request

- Game Calendar

  View upcoming games with details about opponents, times, and locations

- FAQ

  Access walkthroughs and frequently asked questions

- Notifications

  Information about time changes, location changes, or game cancellations

# Prerequisites

Before running, make sure the following are installed:
- Node.js
- Git
- Code editor like Visual Studio Code

# Setting Up

Clone the repo.
In your terminal: 

cd TeamUp
npm install
npm run dev
